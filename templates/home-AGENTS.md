Rules for anyone, person or agent, working here.

## Working together

- Ask the owners before anything that can't be taken back: pushing to the main branch,
  publishing, deploying, deleting data, sending messages for the project.
- One job, one branch, one pull request. Describe in the pull request what changed and why.
- Record decisions in `DECISIONS.md`, newest first: `## <YYYY-MM-DD HH:MM>: <decision>`, then
  `Why:` and `Alternatives considered:`.
- Everything a collaborator needs lives in this repository. Nothing here refers to files or
  notes outside it.
