# Measurement scaffolding

Paused, opt-in measurement tools. These files do not change ordinary test execution or default CLI eligibility.

`measure_cli_panel.py` compares the exact hashed 64-method panel in subprocess and safety-retained inprocess modes on one frozen checkout. It reuses the existing fresh-module scenario adapter. `panel_probe/` counts Python-owned launches and synchronous Git waits; Git Trace2 supplies independent native-process coverage. `summarize.py` requires a complete successful pair with flushed terminal records and identical source hashes.

Partial or stopped runs provide no panel speedup, full-suite projection, or rollout qualification. No rollout is implemented.
