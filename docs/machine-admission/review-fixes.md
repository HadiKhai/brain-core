## Real CLI proof

[`proof.txt`](proof.txt), generated by [`prove.py`](prove.py), runs the worktree CLI with live disk
sampling, a UTC subprocess host, a generic Asia/Beirut instance, and disposable policy/state. It
asserts the deadline's exact epoch, rejects a floor above the measured reserve, demonstrates
hold -> admitted -> expired hold, asserts exactly one expiry record across repeated reads, and
compares the base-policy SHA256 before/after. No production policy is read for mutation or rewritten.

The initial proof reused a four-second deadline across the tightening rejection and the actual
admission; the real sampler consumed that window and the command correctly refused it. The corrected
proof sets a fresh admission deadline after the negative case, sized from the measured sample-command
cost and the three commands to execute before expiry. No command timeout was raised and no check
was weakened. Temporary instance/state is removed by its own context manager.
